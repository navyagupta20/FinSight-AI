# 📈 FinSight AI - Market Intelligence Dashboard

FinSight AI is an interactive stock market analysis dashboard built using Python and Streamlit. It helps users explore historical stock prices, analyze technical indicators, compare assets, and evaluate an experimental machine learning-based price forecasting model.

## ✨ Features

- **Stock Market Analysis:** Explore historical stock prices across supported markets.
- **Technical Indicators:** Analyze Simple Moving Averages (SMA), Relative Strength Index (RSI), and Bollinger Bands.
- **Market Visualization:** View interactive price charts, daily returns, and drawdown trends.
- **Risk Analysis:** Examine total returns, daily volatility, maximum drawdown, and trading volume.
- **Stock Comparison:** Compare multiple assets using normalized performance charts and financial metrics.
- **Machine Learning:** Experiment with Linear Regression for price estimation and evaluate predictions using MAE, RMSE, and directional accuracy.
- **Interactive Dashboard:** Select assets, historical periods, and comparison options through a Streamlit interface.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas and NumPy
- Plotly
- yfinance
- Scikit-learn
